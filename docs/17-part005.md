# Part 005 — the rotozoomer

`NEUROSIS.005`, MOD *Neurotic Interlude*. 137 functions, three scenes.

## Scene 2 — rotozoom with segment:offset texture addressing

The best trick in the demo.

`Demo_Scene2_Rotozoom` (`1096:03d7`) loads a 320×200 image, then **copies it
into a 256-wide buffer**:

```pascal
for Y := 0 to 199 do
  for X := 0 to 255 do
    Texture[Y * 256 + X] := Screen[Y * 320 + 4 + X];
```

The buffer is `GetMem($FFFF)` — a full 64K segment. That is the whole point:

```pascal
Dest[X] := Mem[Hi(V) : Hi(U)];      { Rotozoom_Frame, 1096:0000 }
```

The high bytes of the 16-bit fixed-point coordinates are used **directly as a
segment:offset pair**. `Hi(V)` picks the row, `Hi(U)` the column, and wrapping
is free because both wrap at 256 by construction. No masking, no bounds check,
no multiply — one `MOV` per pixel.

The inner loop is the standard incremental rotation:

```
for Y := 0 to 194 do
  U := X0; V := Y0
  for X := 0 to 319 do
    V := V + dV;  U := U + dU
    Dest^ := Texture[Hi(V):Hi(U)]
  X0 := X0 + dV;  Y0 := Y0 - dU
```

Motion comes from 2,001-entry sin/cos tables built at startup and scaled by 100
and 160; the scene runs until the path index reaches 1,980.

## Scene 1 — a filled-polygon 3-D terrain

`Demo_Scene1` (`100e:07a4`). A 32x32 heightfield rendered as solid triangles.

The three 1,024-byte tables read from `$153DE5` are **heightmaps** — 1024 =
32 x 32. Three routines do the work:

| Routine | Job |
|---|---|
| `100e:056d` | `Z[i] := 250 - (Height[i] - Threshold)` when the height clears the threshold, else 250 |
| `100e:05d3` | project all 1024: `X := 160 - (x shl 6) div Z`, `Y := 100 + (y shl 6) div Z`, `Colour := ((250 - Z) mod 255) + 1` |
| `100e:062a` | clear, then fill **1922 triangles** from 5-byte vertex records, then blit |

1922 = 2 x 31 x 31 — exactly a 32x32 grid triangulated. Colour comes from depth,
so the terrain shades with distance.

The animation is a **threshold sweep**: `SweepDownAndUp` runs the threshold from
one bound to the other and back, so the landscape rises out of the plane and
sinks again. Called with (`$14`, `$41`) twice and (`5`, `$37`) once.

## Scene 3 — a rotating 3-D heightmap

`Heightmap_Draw` (`1102:0000`) draws a **30×30 patch** of the source image
around a moving centre. Each cell's pixel value is used **both as its colour and
as its height**, so the picture embosses itself into the surface:

```pascal
H := Image[CY + J - 15, CX + I - 15];
Rotate(I - 15, J - 15, -50);  Z := Z + 200;  Project;
ScreenX := 320 - X;
ScreenY := Y - 500 + H;          { the height term }
PutPixel(ScreenX, ScreenY, H);
```

`Scene3_Run` (`1102:017e`) bounces that centre around the screen with velocity
(2, 2), reflecting off all four edges, with a scripted pause: velocity drops to
zero at frame 100 and resumes at frame 220. After frame 499 a palette effect
runs; it ends at frame 563.
